## 命名和 ID

文件名：`EXP-YYYYMMDD-NN-short-name.md`，正文第一行标题包含相同 ID。

同一问题的重复采样没有新变量时，合并成一个实验记录；引入了新的决定性对照时再建新 ID。

## 记录尺度

默认用一两段或一个小表即可。只记录会影响结果的设备、ROM、权限、App 版本和环境条件；
操作、判据、结论边界也按需写。小型探测若只更新已存在的事实，直接更新该事实的来源和核验日期，
不建实验页。一个问题连续跑几轮时复用同一 ID，只补新增变量和结论。

可复制的原始输出只在确有回归价值时纳入仓库。大体积、敏感或第三方原件留在本地忽略目录，
记录准确位置和缺失风险。
