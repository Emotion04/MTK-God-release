## 明确不做

- **实验室的自动判定**（原来叫「测一遍」）。判据节点在 shell 身份下读不到
  （`/dev/cpuctl/*` 是 `0660 system`、`/proc/perfmgr/**` 的 SELinux 域进不去），
  本机无 root、Shizuku 就是 uid 2000，没有更高的路。19 项里能自动判的 4 项
  恰好是会掉核的那几个。**效果本来就是体感，用户比节点读数更有发言权** ——
  所以改成用户自己标，不再往这个方向投工。
